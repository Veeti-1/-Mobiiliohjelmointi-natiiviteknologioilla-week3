 ### miksi MVVM on hyödyllinen Compose-sovelluksissa
   - MVVM(Model-View-ViewModel) on suunnittelumalli, joka erottaa sovelluksen vastuualueet.
   - View: UI ja käyttäjän vuorovaikutus
   - ViewModel: UI-logiikka ja tilan hallinta
   - Model: Liiketoimintalogiikka ja data
   - MVVM parantaa koodin vian etsintää, luettavuutta ja koodin ylläpitoa.
   - UI-renderöinti -> View
   - UI-logiikka ja tilanhallinta -> ViewModel
   - Datalogiikka/luokat -> Model
### StateFlow
  - StateFlow on tilanhaltija, joka lähettää nykyiset ja uudet tilapäivitykset keräilijöille.
  - Muutos tilassa päivittää composablet automaattisesti
